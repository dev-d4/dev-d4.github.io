01 — About

Impact over tech stack

I'm an engineer with a Master's degree in Engineering Physics from KTH. I write code because I like it, and I've spent my career on the messy side of it: taking something that works in principle and making it work in someone's actual environment.

At Säkra I own a client risk model end to end — methodology, Python, Azure, SQL — running continuously for tens of thousands of clients. I also own the firm's order, custody and asset management platform: I set it up, integrated it, and run it day to day. Most weeks that means chasing down why an integration broke, sitting between the business, compliance and external developers to work out what's actually needed, and writing the code that fills whatever the system doesn't do. Then automating it so it doesn't come back.

My first years as an engineer were in healthcare, at Karolinska University Hospital — ML models for pulmonary disease classification, segmentation algorithms for medical imaging, and earlier an iOS app moving glucose readings to the cloud over FHIR. I know what it's like to build software that clinicians and patient data depend on.
