01 — About

Background

At Säkra VP I set up and rolled out the firm's custody and asset management platform and own it end to end: configuration, integrations with external financial systems, upgrades and incidents. I diagnose problems that span our own data, the vendor's system and third-party integrations, and build the automated data flows in Python and Pandas that cover the parts the platform doesn't — fee handling, financial reporting, file deliveries.

I am also sole owner of the client risk model, from methodology to production: designed the logic, implemented it in Python, connected it to SQL and deployed it on Azure, released through a GitHub Actions pipeline that runs the test suite before anything reaches production. It runs continuously for tens of thousands of clients.

Before that, healthcare: ML models for pulmonary disease classification at Karolinska University Hospital and the full pipeline from raw clinical imaging data to validated results, and backend integrations moving health data from connected medical devices to the cloud on the FHIR standard.
