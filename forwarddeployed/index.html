01 — About

Background

At Säkra VP most of what I do ends in code that runs in production. I built a flow where Azure OpenAI reads incoming forms and returns structured output, checked field by field against a rule-based extractor so that nothing goes through unless both agree. I built the client risk model and the API around it on Azure Functions, with Azure SQL behind it, alerts in Application Insights and a pytest suite that runs before every release. And I write the Python and Pandas data flows that cover what the vendor platform doesn't — fee handling, financial reporting, file deliveries.

The other half is getting things to work with other people's systems and other people in the room. I rolled out the firm's custody and asset management platform and own it end to end, and I diagnose problems that span our data, the vendor's system and third parties. When a counterparty's API had been stuck for weeks on thin documentation, I tested it endpoint by endpoint, wrote the integration guide and sat with their developers until it ran. I also present to management and the board, train our users and meet clients and counterparties.

Before that, healthcare: ML models for pulmonary disease classification at Karolinska University Hospital and the full pipeline from raw clinical imaging data to validated results, and backend integrations moving health data from connected medical devices to the cloud on the FHIR standard.
